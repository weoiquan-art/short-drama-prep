# short-drama-prep｜短剧筹备

短剧开拍前的流程 Skill：从一句想法到项目简报、剧本、世界规则、人物／道具／场景设定、空间地图、镜头表与时长、选帧、声音与转场计划、连续性检查、分批制作计划。只写文字。

## 现状（2026-10-09，第一版）
- 内容来自 cinematic-prompt-toolkit 完整版（导演模板库 v1.0.0）的 22 个模块中的 19 个（T01–T15、T18–T20、T22），模块正文逐字照搬，分成 5 个文件。
- 按 JIN 2026-10-09 的拆法：T16、T17（视频提示词模板）不收，视频提示词由提示词 Skill 写；T21（失败修复）、《雨停之前》示例、来源与边界放在 video-exp。
- 精简版没有收。

## 第二版（2026-10-09）
- 新增 M6、M7：从豆包官方 Skill（doubao-creative-drama）提炼的 D01–D09——剧作基调与章节、剧本四段产物、长剧本分批、分镜层级与节奏、POV／动作／连续性写法、风格锚点与资产清单、资产顺序与验收、选帧、关键帧图写法。中文是整理者提炼，不是原文；原文存 video-exp（私有）。
- 不收：15 秒片段、画幅限制、一次 2 个视频、提示词尾部负面词、文件交付方式（JIN 2026-10-09）。豆包写视频提示词的部分进真人 Skill（R21）。
